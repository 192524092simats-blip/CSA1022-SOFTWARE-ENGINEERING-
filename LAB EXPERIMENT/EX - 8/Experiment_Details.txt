PROBLEM STATEMENT
Cyclomatic Complexity in Software Testing is a testing metric used for measuring the
complexity of a software program. It is a quantitative measure of independent paths in the
source code of a software program. Cyclomatic complexity can be calculated by using control
flow graphs or with respect to functions, modules, methods or classes within a software
program. Cyclomatic complexity for a flow graph G is V(G)=E-N+2. Cyclomatic complexity is
a software metric (measurement), used to indicate the complexity of a program, Cyclomatic
complexity = E - N + P where, E = number of edges in the flow graph, N = number of nodes in
the flow graph, P = number of nodes that have exit points. Find Cyclomatic Complexity for a
graph having number of edges as 17, number of nodes as 13 and number of predicate nodes in
the flow graph as 5.

AIM
To find the cyclomatic complexity of a program whose flow graph has 17 edges, 13 nodes and 5
predicate nodes, and to verify the result using the alternate formula.

# Experiment 8 - Cyclomatic complexity of a flow graph
import sys
E, N, P = (int(x) for x in sys.argv[1:4]) if len(sys.argv) >= 4 else (17, 13, 5)   # edges, nodes, predicate nodes

v1 = E - N + 2          # V(G) = E - N + 2
v2 = P + 1              # V(G) = P + 1
print(f"Edges E = {E}, Nodes N = {N}, Predicate nodes P = {P}")
print(f"Method 1: V(G) = E - N + 2 = {E} - {N} + 2 = {v1}")
print(f"Method 2: V(G) = P + 1     = {P} + 1 = {v2}")
print("Both methods agree" if v1 == v2 else "Mismatch - recheck the graph")
print(f"Independent paths = {v1}  -> at least {v1} test cases needed for basis-path testing")


EXPECTED OUTPUT
● Using V(G) = E − N + 2 = 17 − 13 + 2 = 6
● Using V(G) = P + 1 = 5 + 1 = 6
● Both methods give V(G) = 6, so at least six independent test paths are required.
