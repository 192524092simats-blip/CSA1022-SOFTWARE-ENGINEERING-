# Experiment 1 – Kanban Board

## Aim
To create a Kanban Board to visualize tasks and simulate the workflow using Trello.

## Tool Used
Trello

## Workflow
To Do → In-Progress → Done

## Sample Tasks
1. Design Login Page
2. Create Database
3. Develop Home Page
4. Testing Module
5. Prepare Documentation

## Result
A Kanban Board was successfully created using Trello. The tasks were moved across To Do, In-Progress, and Done columns to simulate the workflow.
