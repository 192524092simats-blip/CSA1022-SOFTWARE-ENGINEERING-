EXPERIMENT NUMBER : 17
EXPERIMENT TITLE  : FLASK API CONTAINERIZED WITH DOCKER, PUSHED TO DOCKER HUB AND DEPLOYED ON KUBERNETES
TOOLS USED        : Docker & Kubernetes      COURSE OUTCOME: CO3

PROBLEM STATEMENT
Create a Simple Python Flask API, Containerize the Application, Build & Push the Image using
Docker and Deploy the Application using Kubernetes.
Tasks:
● Create a Simple Flask API by writing a Python file (app.py) with basic endpoints.
● Containerize the Flask App using Dockerfile.
● Build the Image using Docker.
● Push the Image to Docker Hub.
● Create Kubernetes manifests (Deployment YAML & Service YAML) to deploy the
   application.
● Apply the Manifests and Access the API via NodePort.

AIM
To create a simple Python Flask API, containerize it with Docker, push the image to Docker Hub
and deploy it on Kubernetes using Deployment and Service (NodePort) manifests.

SOFTWARE REQUIREMENTS
● Python 3 and Flask
● Docker Desktop
● Docker Hub account
● Kubernetes (Docker Desktop Kubernetes or Minikube) and kubectl

PROCEDURE
Step 1: Create the Flask API (app.py)
● Create a project folder flask-api and inside it create app.py:
app.py
 from flask import Flask, jsonify, request
 app = Flask(__name__)
 students = [
      {"id": 1, "name": "Arun", "dept": "CSE"},
      {"id": 2, "name": "Divya", "dept": "IT"},
 ]
 @app.route("/")
 def home():
      return jsonify(message="Hello from Flask API on Kubernetes")
 @app.route("/api/students", methods=["GET"])
 def get_students():
      return jsonify(students)
 @app.route("/api/students", methods=["POST"])
 def add_student():
      data = request.get_json()
      data["id"] = len(students) + 1
      students.append(data)
      return jsonify(data), 201
 @app.route("/health")
 def health():
      return jsonify(status="UP")
 if __name__ == "__main__":
      app.run(host="0.0.0.0", port=5000)
● Create requirements.txt:
requirements.txt
 flask==3.0.3
● Test locally (optional):
 pip install -r requirements.txt
 python app.py
 # open http://localhost:5000/api/students
Step 2: Containerize the Flask App
● Create the Dockerfile:
Dockerfile
 FROM python:3.11-slim
 WORKDIR /app
 COPY requirements.txt .
 RUN pip install --no-cache-dir -r requirements.txt
 COPY app.py .
 EXPOSE 5000
 CMD ["python", "app.py"]
Step 3: Build and Test the Image
● Build the image using your Docker Hub username in the name:
 docker build -t <dockerhub-username>/flask-api:1.0 .
 docker run -d -p 5000:5000 --name api <dockerhub-username>/flask-api:1.0
 curl http://localhost:5000/api/students
 docker stop api && docker rm api
Step 4: Push the Image to Docker Hub
● Log in to Docker Hub (use an access token as the password) and push the image:
 docker login
 docker push <dockerhub-username>/flask-api:1.0
● Open hub.docker.com and verify that the repository flask-api with tag 1.0 is present.
Step 5: Start the Kubernetes Cluster
● Enable Kubernetes in Docker Desktop (Settings → Kubernetes → Enable) or start
   Minikube:
 minikube start
 kubectl get nodes
● The node should be in Ready state.
Step 6: Create the Deployment Manifest
● Create deployment.yaml:
deployment.yaml
 apiVersion: apps/v1
 kind: Deployment
 metadata:
   name: flask-api-deployment
 spec:
   replicas: 2
   selector:
      matchLabels:
        app: flask-api
   template:
      metadata:
        labels:
          app: flask-api
      spec:
        containers:
          - name: flask-api
             image: <dockerhub-username>/flask-api:1.0
             ports:
               - containerPort: 5000
Step 7: Create the Service Manifest (NodePort)
● Create service.yaml:
service.yaml
 apiVersion: v1
 kind: Service
 metadata:
    name: flask-api-service
 spec:
    type: NodePort
    selector:
       app: flask-api
    ports:
       - port: 5000
         targetPort: 5000
         nodePort: 30007
Step 8: Apply the Manifests
 kubectl apply -f deployment.yaml
 kubectl apply -f service.yaml
 kubectl get deployments
 kubectl get pods -o wide
 kubectl get svc
● Verify that 2/2 pods are Running and the service shows 5000:30007/TCP.
Step 9: Access the API via NodePort
● Docker Desktop: open http://localhost:30007/ and http://localhost:30007/api/students
● Minikube: get the URL with the command below and open it in the browser:
 minikube service flask-api-service --url
 curl http://<node-ip>:30007/api/students

----- Dockerfile -----
FROM python:3.11-slim

----- app.py -----
from flask import Flask, jsonify, request
app = Flask(__name__)
students = [
    {"id": 1, "name": "Arun", "dept": "CSE"},
    {"id": 2, "name": "Divya", "dept": "IT"},
]

@app.route("/")
def home():
    return jsonify(message="Hello from Flask API on Kubernetes")

@app.route("/api/students", methods=["GET"])
def get_students():
    return jsonify(students)

@app.route("/api/students", methods=["POST"])
def add_student():
    data = request.get_json()
    data["id"] = len(students) + 1
    students.append(data)
    return jsonify(data), 201

@app.route("/health")
def health():
    return jsonify(status="UP")

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)


----- deploy.sh -----
#!/usr/bin/env bash
# usage: ./deploy.sh <dockerhub-username>
U=${1:?usage: ./deploy.sh <dockerhub-username>}
docker build -t $U/flask-api:1.0 .
docker run -d -p 5000:5000 --name api $U/flask-api:1.0 && sleep 2 && curl http://localhost:5000/api/students
docker stop api && docker rm api
docker login && docker push $U/flask-api:1.0
sed -i "s#<dockerhub-username>#$U#" deployment.yaml
kubectl apply -f deployment.yaml && kubectl apply -f service.yaml
kubectl get deployments && kubectl get pods -o wide && kubectl get svc
curl http://localhost:30007/ ; curl http://localhost:30007/api/students   # Minikube: minikube service flask-api-service --url


----- deployment.yaml -----
apiVersion: apps/v1
kind: Deployment
metadata:
  name: flask-api-deployment
spec:
  replicas: 2
  selector:
    matchLabels:
      app: flask-api
  template:
    metadata:
      labels:
        app: flask-api
    spec:
      containers:
        - name: flask-api
          image: <dockerhub-username>/flask-api:1.0
          ports:
            - containerPort: 5000


----- requirements.txt -----
flask==3.0.3


----- service.yaml -----
apiVersion: v1
kind: Service
metadata:
  name: flask-api-service
spec:
  type: NodePort
  selector:
    app: flask-api
  ports:
    - port: 5000
      targetPort: 5000
      nodePort: 30007
