EXPERIMENT NUMBER : 28
EXPERIMENT TITLE  : PULLING COLLABORATOR CHANGES FROM GITHUB
TOOLS USED        : Git/GitHub      COURSE OUTCOME: CO4

PROBLEM STATEMENT
You cloned a repository earlier, and now another collaborator has made changes to it. You need
to pull the latest changes from GitHub to keep your local copy up to date.
Tasks:
● Clone a repository (from previous questions).
● Ask a collaborator to make a change and push it to the GitHub repository.
● Use git pull origin main to pull the latest changes.
● Verify that the changes made by your collaborator appear in your local repository.

AIM
To pull the latest changes made by a collaborator from the GitHub repository into the local
repository and verify that the local copy is up to date.

SOFTWARE REQUIREMENTS
● Git (Git Bash)
● GitHub (repository with a collaborator)
● Visual Studio Code

PROCEDURE
Step 1: Clone the Repository
● Open Git Bash and navigate to the desired location.
● Clone the existing GitHub repository using the git clone command.
● Wait for the cloning process to complete successfully.
 git clone <repository_url>
Step 2: Navigate to the Repository
● Move into the cloned repository directory.
● Verify that the repository files are available.
 cd <repository_name>
 ls
Step 3: Ask the Collaborator to Make Changes
● Ask a collaborator to open the same GitHub repository.
● The collaborator makes a small change to a file, such as README.md.
● The collaborator stages and commits the change.
 git add README.md
 git commit -m "Updated README by collaborator"
● The collaborator pushes the changes to the main branch.
 git push origin main
Step 4: Check the Local Repository
● Return to your local Git Bash.
● Check the current status of your repository.
 git status
● Verify that your local repository has not yet received the collaborator's changes.
Step 5: Pull the Latest Changes
● Download and merge the latest changes from the GitHub main branch using:
 git pull origin main
● Wait for Git to complete the pull operation successfully.
Step 6: Verify the Pulled Changes
● Open the repository in Visual Studio Code:
 code .
● Open the file modified by the collaborator.
● Verify that the collaborator's changes are now available in your local repository.
Step 7: Confirm the Repository is Updated
● Run the following command:
 git status
● Verify that the working tree is clean and the local repository is synchronized with the remote
   repository.

SOURCE CODE (files in Source_Code/)

----- pull_collaborator_changes_demo.sh -----
#!/usr/bin/env bash
# Experiment 28 - pull collaborator changes
# Runs the whole workflow on your machine. A local bare repository (origin.git) plays the role of GitHub,
# so no account or internet is needed. For the REAL GitHub steps follow the Procedure in Experiment_Details.txt.
set -e
W=$(mktemp -d); cd "$W"
export GIT_AUTHOR_NAME="Student" GIT_AUTHOR_EMAIL="student@example.com" GIT_COMMITTER_NAME="Student" GIT_COMMITTER_EMAIL="student@example.com"
export GIT_MERGE_AUTOEDIT=no GIT_EDITOR=true
git config --global init.defaultBranch main 2>/dev/null || true
git init -q --bare -b main origin.git
git clone -q origin.git seed 2>/dev/null; cd seed; git checkout -q -b main 2>/dev/null || true
printf '# My-Personal-Project\n\nInitial README created on GitHub.\n' > README.md
git add README.md; git commit -q -m "Initial commit"; git push -q origin main; cd ..; rm -rf seed
show() { echo; local s="\$"; for a in "$@"; do case "$a" in *\ *) s="$s '$a'";; *) s="$s $a";; esac; done; echo "$s"; "$@" 2>&1; }

git clone -q origin.git mine
git clone -q origin.git collaborator
( cd collaborator; echo "Line added by the collaborator." >> README.md; git add README.md
  git commit -q -m "Updated README by collaborator"; git push -q origin main )
cd mine
echo "(collaborator has pushed a commit to origin)"
show git pull origin main
show cat README.md
show git status
show git log --oneline

echo; echo "Workspace: $W"


EXPECTED OUTPUT
● Collaborator’s commit “Updated README by collaborator” is pushed to GitHub.
● git pull origin main shows Fast-forward, 1 file changed.
● README.md in VS Code shows the collaborator’s change; git status reports the branch is
   up to date.
