# Experiment 25 - Creating a GitHub Repository and Pushing a Readme File

**Tools:** Git/GitHub | **Course Outcome:** CO3

## Aim
To create a new GitHub repository for a personal project, clone it, add a project description to
the README.md file, and commit and push the changes to GitHub.

## Software Requirements
● Git (Git Bash)
● GitHub account
● Visual Studio Code
