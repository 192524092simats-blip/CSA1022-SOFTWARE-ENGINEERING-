# Experiment 12 - Prioritizing Task Management System Requirements using MoSCoW and Kano in Jira

**Tools:** Jira | **Course Outcome:** CO2

## Aim
To create the requirements of a Task Management System as Jira issues and prioritize them
using the MoSCoW and Kano models.

## Software Requirements
● Jira Software (Cloud) – Scrum project
● Web browser

## Source_Code
- `task_management_requirements.csv`

## How to run
Create the Scrum project, import `task_management_requirements.csv` (labels = MoSCoW + Kano) and follow the Procedure.

## Expected Output
● Scrum project “Task Management System” with four requirements created as tasks and
   added to Sprint 1.
● MoSCoW: Login & Role Assignment – Must; Task Creation & Assignment – Must; Task
   Prioritization & Deadlines – Should; Progress Tracking & Reporting – Could.
● Kano: Login & Role Assignment – Basic; Task Creation & Assignment – Basic; Task
   Prioritization & Deadlines – Performance; Progress Tracking & Reporting – Excitement.
