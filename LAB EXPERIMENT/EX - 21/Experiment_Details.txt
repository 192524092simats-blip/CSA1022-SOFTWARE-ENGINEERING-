Step 2: Create the Dockerfile
Dockerfile
 FROM python:3.11-slim
 WORKDIR /app
 COPY requirements.txt .
 RUN pip install --no-cache-dir -r requirements.txt
 COPY . .
 EXPOSE 5000
 CMD ["python", "app.py"]
● Create .dockerignore containing __pycache__ and *.pyc so that unnecessary files are not
   copied.
Step 3: Build the Docker Image
 docker build -t todo-app:1.0 .
 docker images todo-app
Step 4: Run the Container Locally
 docker run -d --name todo -p 5000:5000 todo-app:1.0
 docker ps
● Open http://localhost:5000 in the browser.
Step 5: Test the Application Functionality
● Add three tasks (e.g. “Complete SE record”, “Prepare viva”, “Submit assignment”), mark
   one as Done and delete one.
● Test the JSON endpoint from the host and from inside the container:

 urllib.request;print(urllib.request.urlopen('http://localhost:5000/api/tasks').read())
 "
 docker logs todo
● The response shows the list of tasks in JSON, and the logs show the GET/POST requests.
Step 6: Push the Image to Docker Hub
 docker login

● Verify the repository on hub.docker.com.

----- app.py -----
from flask import Flask, render_template, request, redirect, url_for, jsonify
app = Flask(__name__)
tasks = []            # in-memory list of tasks

@app.route("/")
def index():
    return render_template("index.html", tasks=tasks)

@app.route("/add", methods=["POST"])
def add():
    title = request.form.get("task", "").strip()
    if title:
        tasks.append({"id": len(tasks) + 1, "title": title, "done": False})
    return redirect(url_for("index"))

@app.route("/done/<int:task_id>")
def done(task_id):
    for t in tasks:
        if t["id"] == task_id:
            t["done"] = True
    return redirect(url_for("index"))

@app.route("/delete/<int:task_id>")
def delete(task_id):
    global tasks
    tasks = [t for t in tasks if t["id"] != task_id]
    return redirect(url_for("index"))

@app.route("/api/tasks")
def api_tasks():
    return jsonify(tasks)

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
