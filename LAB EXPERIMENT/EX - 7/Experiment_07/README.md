# Experiment 07 - UML Diagrams for a College Security Management System

**Tools:** Umbrello | **Course Outcome:** CO1

## Aim
To design the Class diagram, Use Case diagram and Activity diagram for a Security
Management System that manages the security personnel of a college.

## Software Requirements
● Umbrello UML Modeller / StarUML
● Windows / Linux PC

## Source_Code
- `activity_diagram.dot`
- `class_diagram.dot`
- `usecase_diagram.dot`

## How to run
Recreate the diagrams in Umbrello/StarUML from the Procedure. `.dot` sources + exported PNGs are included; regenerate with `dot -Tpng class_diagram.dot -o class.png` (Graphviz).

## Expected Output
● Class diagram of the Security Management System with attributes, methods and
   associations.
● Use Case diagram with all actors and use cases inside the system boundary.
● Activity diagram showing the duty and incident-reporting workflow.
