# Experiment 09 - Creating a Scrum Project with Backlog and Sprint in Jira

**Tools:** Jira | **Course Outcome:** CO2

## Aim
To create a Scrum project in Jira, add user stories to the product backlog, plan a sprint, start the
sprint and track the work on the sprint board.

## Software Requirements
● Jira Software (Cloud)
● Web browser
● Atlassian account

## Source_Code
- `README_import.txt`
- `scrum_backlog.csv`

## How to run
Create the Scrum project in Jira; `Source_Code/scrum_backlog.csv` can be imported for the five backlog items.

## Expected Output
● A Jira Scrum project is created.
● User stories and tasks are created in the backlog and estimated.
● Sprint 1 is created, issues are moved into it and the sprint is started; the board shows the
   issues under To Do / In Progress / Done.
