EXPERIMENT NUMBER : 18
EXPERIMENT TITLE  : CI/CD PIPELINE WITH JENKINS FOR A CONTAINERIZED APPLICATION
TOOLS USED        : Docker      COURSE OUTCOME: CO4

PROBLEM STATEMENT
Set up a CI/CD pipeline to automate the building, testing, and deployment of a containerized
application.
Tasks:
● Set up Jenkins on a local machine or server.

AIM
To set up Jenkins and create a CI/CD pipeline that automatically builds, tests and deploys a
containerized application whenever code is pushed to the repository.

SOFTWARE REQUIREMENTS
● Jenkins (LTS) – run as a Docker container or installed locally
● Docker
● Git and GitHub
● Python 3 / Flask sample application

PROCEDURE
Step 1: Run Jenkins using Docker
● Start Jenkins LTS as a container. The Docker socket is mounted so that Jenkins can run
   Docker commands:
 docker volume create jenkins_home
 docker run -d --name jenkins -p 8080:8080 -p 50000:50000 \
   -v jenkins_home:/var/jenkins_home \
   -v /var/run/docker.sock:/var/run/docker.sock \
   jenkins/jenkins:lts
● Install the Docker CLI inside the Jenkins container (one time):
 docker exec -u root jenkins bash -c "apt-get update && apt-get install -y docker.io"
 docker exec -u root jenkins chmod 666 /var/run/docker.sock
● (Alternatively, install Jenkins on Windows using the .msi installer from jenkins.io.)
Step 2: Unlock and Configure Jenkins
● Get the initial admin password:
 docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword
● Open http://localhost:8080, paste the password, choose Install suggested plugins and create
   the admin user.
● Go to Manage Jenkins → Plugins and make sure Git, Pipeline and Docker Pipeline plugins
   are installed.
Step 3: Prepare the Application Repository
● Create a GitHub repository jenkins-flask-demo with app.py, test_app.py, requirements.txt,
   Dockerfile and Jenkinsfile.
app.py
 from flask import Flask
 app = Flask(__name__)
 @app.route("/")
 def home():
      return "CI/CD with Jenkins - Build successful!"
 if __name__ == "__main__":
      app.run(host="0.0.0.0", port=5000)
test_app.py
 from app import app
 def test_home():
      client = app.test_client()
      resp = client.get("/")
      assert resp.status_code == 200
      assert b"Jenkins" in resp.data
requirements.txt
 flask==3.0.3
 pytest==8.2.0
Dockerfile
 FROM python:3.11-slim
 WORKDIR /app
 COPY requirements.txt .
 RUN pip install --no-cache-dir -r requirements.txt
 COPY . .
 EXPOSE 5000
 CMD ["python", "app.py"]
Step 4: Write the Jenkinsfile
● Add the declarative pipeline to the root of the repository:
Jenkinsfile
 pipeline {
      agent any
      environment {
            IMAGE = "flask-cicd"
            TAG    = "${env.BUILD_NUMBER}"
      }
      triggers { pollSCM('H/2 * * * *') }         // check GitHub every 2 minutes
      stages {
            stage('Checkout') {
                steps { git branch: 'main', url:
 'https://github.com/<username>/jenkins-flask-demo.git' }
            }
            stage('Build Image') {
                steps { sh 'docker build -t $IMAGE:$TAG .' }
            }
            stage('Test') {
                steps { sh 'docker run --rm $IMAGE:$TAG pytest -q' }
            }
            stage('Deploy') {
                steps {
                     sh 'docker rm -f flask-app || true'
                     sh 'docker run -d --name flask-app -p 5000:5000 $IMAGE:$TAG'
                }
            }
      }
      post {
            success { echo 'Pipeline completed: application deployed on port 5000' }
            failure { echo 'Pipeline failed - check the console output' }
      }
 }
● Commit and push all files to GitHub.
Step 5: Create the Pipeline Job
● On the Jenkins dashboard click New Item → enter flask-cicd → select Pipeline → OK.
● Under Pipeline choose Definition: Pipeline script from SCM, SCM: Git, enter the repository
   URL, branch */main and Script Path Jenkinsfile.
● Click Save.
Step 6: Run the Pipeline
● Click Build Now. Open the build and view Console Output and the Stage View.
● All stages Checkout, Build Image, Test and Deploy should be green.
Step 7: Verify the Deployment
● Open http://localhost:5000 – the message “CI/CD with Jenkins - Build successful!” is
   displayed.
 docker ps
 curl http://localhost:5000
Step 8: Test Automatic Triggering
● Change the message in app.py and the test, commit and push to GitHub.
● Within two minutes Jenkins polls the repository and starts a new build automatically (or
   configure a GitHub webhook to http://<jenkins-host>:8080/github-webhook/).
● Verify that the new version is deployed.
