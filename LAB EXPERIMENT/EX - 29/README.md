# Experiment 29 - Feature Branch (Feature-Login) And Pull Request

**Tools:** Git/GitHub | **Course Outcome:** CO4

## Aim
To create a feature branch named feature-login, implement a simple login function in login.py,
commit and push it, and create and merge a pull request into the main branch.

## Software Requirements
● Git (Git Bash)
● GitHub
● Visual Studio Code
● Python 3

## Source_Code
- `feature_login_demo.sh`

## How to run
`bash feature_login_demo.sh` shows the flow locally; `python login.py` runs the login function.

## Expected Output
● Branch feature-login created; login.py added and committed (“Added login function”).
● Pull request “Add Login Function” created from feature-login to main and merged.
● After git checkout main and git pull, login.py is present in main.
