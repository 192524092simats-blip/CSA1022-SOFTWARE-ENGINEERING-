# Experiment 10 - MoSCoW Prioritization of Library Management System Requirements

**Tools:** Google Sheet or Excel | **Course Outcome:** CO2

## Aim
To categorize the requirements of a Library Management System into Must-Have, Should-Have,
Could-Have and Won’t-Have using the MoSCoW method, with justification based on impact
and feasibility, in Google Sheets / Excel.

## Software Requirements
● Google Sheets or Microsoft Excel

## Source_Code
- `Library Management System - MoSCoW Prioritization.xlsx`
- `create_moscow_workbook.py`

## How to run
`pip install openpyxl` then `python create_moscow_workbook.py` creates the Excel file (it opens in Google Sheets too).

## Expected Output
● A spreadsheet “Library Management System – MoSCoW Prioritization” with columns
   Requirement ID, Requirement Description, MoSCoW Category and Justification.
● All ten requirements categorized and justified, with formatted headings and colour-coded
   categories.

## Result
Thus the requirements of the Library Management System were prioritized using the MoSCoW
method with suitable justification and submitted as a spreadsheet.
