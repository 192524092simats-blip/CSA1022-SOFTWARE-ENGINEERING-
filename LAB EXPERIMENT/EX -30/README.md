# Experiment 30 - Forking, Feature Branch and Pull Request to the Original Repository

**Tools:** Git/GitHub | **Course Outcome:** CO4

## Aim
To fork a team member’s repository, clone it, create a feature branch, implement a feature
without affecting existing code, push it to the fork and submit a pull request to the original
repository.

## Software Requirements
● Git (Git Bash)
● GitHub
● Visual Studio Code

## Source_Code
- `fork_feature_pr_demo.sh`

## How to run
`bash fork_feature_pr_demo.sh` shows the flow locally. Real GitHub steps are in the Procedure.

## Expected Output
● Fork of 3-Simple-Python-Projects created and cloned.
● Branch feature-update created; ytDownloader.py modified, committed (“Added project info
   feature”) and pushed.
● Pull request from the fork’s feature-update branch to the original repository’s main branch is
   opened.
